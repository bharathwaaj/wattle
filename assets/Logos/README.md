# Logos

The Wattle mark is the lapwing's eye ring: a yellow ring and dot on a cap-black disc. Every file has its colours baked in, so pick the one that matches your background.

| File | Use on | Inks |
| --- | --- | --- |
| `wattle-mark.svg` | Light backgrounds (`surface-100`, `surface-200`) | `ink` disc, `wattle` ring and dot |
| `wattle-mark-dark.svg` | Dark backgrounds | `wattle` disc, `ink` ring and dot |
| `wattle-wordmark.svg` | Light backgrounds | `ink`. "Wattle" in Fraunces 600, converted to outlines |
| `wattle-wordmark-dark.svg` | Dark backgrounds | `ink` from the dark theme (`#F3EFE6`) |
| `wattle-lockup.svg` | Light backgrounds: headers, documents | Mark and wordmark side by side |
| `wattle-lockup-dark.svg` | Dark backgrounds | Mark and wordmark side by side |
| `favicon.svg` | Browser tab icon | The same as `wattle-mark.svg` |
| `favicon-32.png` | Browser tab icon, fallback for older browsers | 32×32 |
| `apple-touch-icon.png` | Home-screen icon on iOS | 180×180 |

## Rules

- Keep clear space around the mark equal to the ring's stroke width on every side.
- The smallest size for the mark is 16px. The smallest height for the wordmark is 14px.
- Don't recolour, outline, rotate or stretch the mark. Never put the yellow ring straight on a light background without its disc.
- Use the lockup where the name needs to be read. Use the mark alone where space is tight, such as avatars, favicons and app icons.
