# Icons

The icons are a starter set from [Lucide](https://lucide.dev) v0.460.0, released under the ISC licence (see `LICENSE.txt`).

To match the brand book, they're adjusted from Lucide's defaults:

- **1.5px stroke** instead of 2px
- **`ink` colour** (`#1F1D1B`) baked into each file, so they display correctly inside `<img>` tags

## Using them

- In code, inline the SVG and change `stroke="#1F1D1B"` to `stroke="currentColor"`. The icon then follows the surrounding text colour (`ink`, `ink-muted` or `danger`), which also makes it work in the dark theme.
- Draw them at 24px, or at 20px in dense UI. Keep them at the same size as the text they sit next to.
- Never colour an icon `wattle`.
- When you need an icon that isn't here, take it from Lucide v0.460.0 and apply the same two changes.
