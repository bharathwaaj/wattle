# Avatar

A round initials badge for a person: `ink` on `taupe` (6:1), in Fraunces.

## You provide

- `name`: used for the initials (first and last word) and as the accessible name.
- `initials`: optional, to override the computed ones.
- `size`: in px. The default is 48.

## Do and don't

- Do put the name in text next to it. The avatar supports the name, it doesn't replace it.
- Don't colour avatars by person. Taupe keeps lists calm.
