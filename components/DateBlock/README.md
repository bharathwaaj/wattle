# DateBlock

A calendar-page date: the month in small caps above the day in large Lora. Put it beside an event's title.

## You provide

- Either `date` (anything `new Date()` accepts), or `month` and `day`.
- `label`: optional. The full spoken date, e.g. "Tuesday 18 November". It defaults to "18 NOV".

## Do and don't

- Pair it with a MetaList for the time and place.
- Don't use it for ranges or deadlines. Write those out in words.
