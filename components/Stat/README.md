# Stat

One big number in Newsreader, with an optional unit and a one-line trend. The number rolls in when it changes.

## You provide

- `value`, `unit` (optional) and `label` (optional overline).
- `trend`: written out in words, e.g. "Up 4 points on last week".
- `trendDirection`: `up` (default), `down` or `flat`. It sets the arrow, and the words carry the meaning.

## Do and don't

- Show one stat per card, or a row of 2–4 in a dashboard.
- Don't colour trends red or green. Say what happened in the words.
