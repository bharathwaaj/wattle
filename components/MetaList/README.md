# MetaList

Rows of small details (dates, times, places, people), each with a 16px icon, in `ink-muted`.

## You provide

- `items`: an array of `{ icon, text }`, where `text` can be any node.

## Do and don't

- Keep it to 2–4 rows, with one fact per row.
- Use icons people know: calendar for the day, clock for the time, user for people.
