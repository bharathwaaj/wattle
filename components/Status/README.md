# Status

A coloured dot and a word that say what state something is in. It's lighter than a Badge, so use it in lists and tables.

## Tones

- **live**: a `danger` dot that pulses. Use it only for things happening right now, like a live class.
- **active**: a `wattle` dot with an `ink` ring. Use it for "in progress".
- **done**: an `ink` dot.
- **neutral** (default): a `border-strong` dot. Use it for draft or scheduled items.
- **danger**: a `danger` dot and text. Use it for overdue or failed items.

## Do and don't

- The word always carries the meaning, and the dot only helps people scan.
- Don't use more than one `live` status per screen.
